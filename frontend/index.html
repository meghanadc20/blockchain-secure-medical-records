About the platform

Medical files stay off the blockchain. The blockchain records who was given access and the fingerprint of each file, so changes and permissions can be checked independently.

Encrypted off-chain storage

Files are encrypted before storage and only released by the server after a permission check.

Patient-controlled access

Approve, reject or revoke doctor access. Revoked or expired access is denied immediately.

Integrity & audit trail

Each file's SHA-256 hash is compared on retrieval to detect tampering, and every access is logged.
